## 홈 구성 (위에서 아래로)
1. **첫 화면**: "직접 쓰려고 만듭니다." + 실제 앱 화면 폰 두 대(퀀트뷰 시장, 러닝뷰 대회 일정). 스크롤하면 멈춘 채 작아지고 다음 구역이 덮는다.
2. **선언문**: 둥근 회색 시트 위 문장이 한 단어씩 또렷해지고 뒤에서 코발트 빛이 번진다. 문장 안에 앱 아이콘.
3. **출시한 앱**: 퀀트뷰(밝은 타일)·러닝뷰(어두운 타일). 아이콘이 날아와 앉고 아래에 실제 앱 화면.
4. **만든 앱 코스**(서명 동작): 어두운 무대에 고정된 채 코발트 선이 그려지고, 선이 닿을 때마다 만든 것 5개(퀀트뷰 → 텔레그램 봇 → 카카오톡 봇 → 트럼프봇 → 러닝뷰)가 켜지며 숫자가 0 → 5. 각 항목은 상세 페이지 링크. `components/BuildRoute.tsx`.
5. **지금 만들고 있어요**: 러닝뷰 대회 응원, PokeView, 토스증권 자동매매.
6. **소개**: 크루 야간 훈련 사진 + "앱 만들고, 달립니다."
7. **연락**: 협업·협찬 문의 / 개발 제안 / 앱 문의 / 인스타그램 DM.

- 움직임은 전부 CSS(`app/globals.css` "움직임 = 스크롤 이야기"). 추가 라이브러리 없음.
- 파이어폭스처럼 지원하지 않는 브라우저, "동작 줄이기" 사용자에게는 긴 고정 구역 없이 완성된 모습이 보인다.
- 첫 화면이 뒤에 멈춰 있는 구조라 **그 뒤 구역은 모두 배경색이 있어야** 한다.
