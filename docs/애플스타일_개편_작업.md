# 애플 스타일 개편 + 인스타 링크 페이지 (2026-09-29)

## 무엇이 바뀌었나
- **메인(/)**: 애플 홈페이지처럼 큰 제목, 넓은 여백, 흰색 → 회색 → 흰색 → 검정 → 회색 구역이 번갈아 나오게 바꿨습니다.
  구역 순서 = 첫 화면 → 출시한 앱(퀀트뷰·러닝뷰 큰 타일 + 봇 3개) → 지금 만들고 있어요 → 소개(러닝 기록) → 연락.
- **인스타 링크 페이지(/links)**: 인스타 프로필에 넣을 한 장짜리 페이지. 휴대폰에서 한 줄로 쭉 내려 보는 구성.
  순서 = 로고·이름·러닝 기록 → 러닝뷰(가장 크게) → 퀀트뷰 → 봇 → 만드는 중 → 연락 → 다른 채널.
- **색**: `app/globals.css` 의 색 변수 값을 애플 색으로 교체 (글자 #1d1d1f, 회색 구역 #f5f5f7, 파랑 #0071e3).
  상세 페이지들도 같은 변수를 쓰므로 자동으로 새 색을 따라갑니다.
- **한글 줄바꿈**: 낱말 가운데서 끊기지 않게 `word-break: keep-all` 적용.
- **움직임**: 첫 화면 등장 1번 + 스크롤하면 카드가 떠오르는 효과 1종류만. "움직임 줄이기" 설정 사용자에게는 꺼집니다.

## 스크롤 이야기 (2026-09-29 2차, "섞어서 최대로")
전부 CSS 로 만들었습니다(추가 설치 없음). 설정은 `app/globals.css` 의 "움직임 = 스크롤 이야기" 한 곳에 모여 있습니다.
1. **첫 화면**: 제목이 머리글 아래에 멈춘 채 작아지며 흐려지고, 다음 검은 구역이 커튼처럼 덮습니다.
2. **선언문**: 검은 화면에 고정된 문장이 스크롤한 만큼 한 단어씩 밝아집니다. 문장은 `app/page.tsx` 의 `MANIFESTO`.
3. **앱 아이콘**: 크게 기울어진 채 날아와 카드 제자리에 앉습니다. 봇 카드·만드는 중 목록은 아래에서 떠오릅니다.
4. **러닝 코스(클라이맥스)**: 파란 선이 코스처럼 그려지면서 km 가 0 → 42 로 올라가고, 선이 10K·하프·풀코스 지점을 지날 때 기록이 튀어나옵니다. 넓은 화면은 가로 코스, 휴대폰은 세로 코스. `components/RunCourse.tsx`.
   - 기록 점 좌표는 곡선 길이 비율로 미리 계산한 값입니다. 곡선 모양을 바꾸면 점 좌표도 다시 계산해야 합니다.
5. **진행 막대**: 머리글 아래 얇은 파란 선이 페이지를 내린 만큼 차오릅니다.

- 파이어폭스처럼 지원하지 않는 브라우저, "동작 줄이기"를 켠 사용자에게는 긴 고정 구역 없이 완성된 모습(42 km, 기록 전부, 밝은 문장)이 그대로 보입니다.
- 첫 화면이 뒤에 멈춰 있는 구조라 **그 뒤 구역은 모두 배경색이 있어야** 합니다(없으면 뒤의 첫 화면이 비쳐 보임).

## AI 티 점검 (2026-09-29 공부: "AI 티 안 나는 웹사이트, 클로드로 만드는 법" 노션 가이드)
가이드 요지: 클로드에게 디자인을 맡기면 매번 같은 글꼴·보라 그라데이션·카드 속 카드가 나온다.
순서 = ① 스킬 설치(Taste Skill + Impeccable) → ② **디자인 기준 파일 만들기(`/impeccable init` → PRODUCT.md·DESIGN.md, 가장 중요)** → ③ 화면 제작 → ④ 검사(`impeccable detect`, 규칙 60개). 하나라도 빠지면 AI 티가 남는다.
기준 파일이 없으면 AI 는 학습된 기본값(무난한 화면)으로 돌아간다. 스킬만 깔고 ②를 건너뛰면 결과가 거의 안 바뀐다.

AI 티 다섯 가지 (가이드) → 대신 요청할 것
1. 글꼴이 늘 Inter·Roboto·시스템 기본값 → 브랜드에 맞는 글꼴을 골라 지정
2. 보라→파랑 그라데이션 → 의도해서 정한 주조색 한 가지
3. 카드 안에 카드 → 여백과 선으로 나눈 납작한 구조
4. 색 있는 배경 위 회색 글자 → 배경과 대비가 확보된 본문 색
5. 튕기는 바운스 효과 → 짧고 자연스럽게 멈추는 움직임

지금 사이트 점검 결과 (검사 프로그램은 약관 페이지 인용 상자 1건만 지적, 아래는 눈으로 찾은 것)
- [큼] 선언문 뒤 빛이 파랑·보라·분홍 그라데이션 = 2번 AI 티. 애플 인텔리전스를 참고해 넣었지만 가장 AI 같은 부분.
- [큼] 글꼴: 본문 Pretendard(한국 사이트 기본값, 영문 모양이 Inter 기반) + 로고 A 모양이 Inter Tight = 1번과 같은 계열.
- [중간] 봇 3개가 똑같은 모양 카드 3칸(아이콘+라벨+제목+설명) = Taste Skill 의 "같은 카드 3개 나란히" 금지 항목.
- [중간] 제목 위 작은 라벨("1인 개발자 lbh939", "출시", "운영 중") = 두 스킬 모두 AI 티로 꼽는 eyebrow.
- [작음] 페이지 제목(브라우저 탭·공유 카드) 16곳의 긴 줄표(—), 러닝 코스 선의 네온 번짐, 순수 검정(#000).
- [없음] 카드 속 카드, 색 배경 위 회색 글자, 바운스 효과 = 해당 없음. 대비·동작 줄이기·폰 크기는 앞서 고침.
- [빠진 것] 실제 사진이 없음(아이콘만). Taste Skill: "글만 있는 페이지는 미완성" → 러닝 사진·앱 화면 캡처를 넣으면 개인 사이트다워짐.
